 u16    | uint16_t     | unsigned 16-bit integer
 s32    | int32_t      | signed 32-bit integer

 u64    | uint64_t     | unsigned 64-bit integer

 f128   | long double  | 128-bit IEE754 floating point

 usize  | size_t       | unsigned pointer sized integer
